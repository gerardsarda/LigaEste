# Liga Este PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an installable, offline-capable PWA checklist for the Liga Este 2026-27 sticker collection, using the Stitch-generated design and the existing Excel checklist, with all state in the browser (no backend).

**Architecture:** Static HTML/CSS/JS SPA in `web/`, Tailwind compiled once to a static stylesheet, fonts/icons self-hosted, catalog data generated from the Excel by a Python script, user progress in `localStorage` seeded from the existing Streamlit progress file, service worker precaching the whole app shell.

**Tech Stack:** Vanilla JS (ES modules), Tailwind CLI (build-time only), openpyxl (data conversion), no runtime framework, no backend.

## Global Constraints

- No Supabase / no backend / no database — all persistent user state lives in `localStorage` on the device. (spec: Contexto)
- `app.py`, `checklist_este_2026_27.xlsx`, `coleccion_progreso_laliga.json` at the project root are not modified. (spec: Alcance)
- Visual language must match `DESIGN.md` tokens and the two Stitch exports (`/tmp/stitch1/code.html` dashboard, `/tmp/stitch3/code.html` team detail) — colors, type scale, spacing, card styles. (spec: Arquitectura)
- No CDN dependencies at runtime (Tailwind, Google Fonts, Material Symbols must be self-hosted) so the app works fully offline. (spec: Offline / instalación)
- Existing user progress (150 obtenidos, 36 repes in `coleccion_progreso_laliga.json`) must be preserved as the seed state, not discarded. (spec: Datos)
- Service worker requires HTTPS/localhost; final deploy target is GitHub Pages, with explicit user confirmation before creating the remote repo / pushing. (spec: Publicación)

- [ ] **Step 2: Write `web/js/app.js`**

```js
import { initState, getStats } from './state.js';

const views = {
  equipos: () => import('./views/equipos.js'),
  cromos: () => import('./views/cromos.js'),
  repes: () => import('./views/repes.js'),
  stats: () => import('./views/stats.js'),
};

async function renderRoute() {
  const root = document.getElementById('view-root');
  const [, name, param] = (location.hash || '#/equipos').split('/');
  const mod = await (views[name] || views.equipos)();
  root.innerHTML = '';
  await mod.default(root, param);
  updateHeaderProgress();
  updateActiveNav(name || 'equipos');
}

function updateHeaderProgress() {
  const { total, obtenidos } = getStats();
  const pct = total ? Math.round((obtenidos / total) * 1000) / 10 : 0;
  document.getElementById('album-count').textContent = `${obtenidos} / ${total}`;
  document.getElementById('album-pct').textContent = `(${pct}%)`;
  document.getElementById('album-bar').style.width = `${pct}%`;
}

function updateActiveNav(name) {
  document.querySelectorAll('#bottom-nav a').forEach(a => {
    a.classList.toggle('text-primary-container', a.dataset.path === name);
    a.classList.toggle('font-bold', a.dataset.path === name);
  });
}

window.addEventListener('hashchange', renderRoute);
window.addEventListener('DOMContentLoaded', async () => {
  await initState();
  if (!location.hash) location.hash = '#/equipos';
  renderRoute();
  if ('serviceWorker' in navigator) navigator.serviceWorker.register('sw.js');
});
```

- [ ] **Step 2: Write `web/sw.js`**

```js
const CACHE = 'liga-este-v1';
const PRECACHE_URLS = [
  './', './index.html', './manifest.webmanifest',
  './css/styles.css', './css/fonts.css',
  './js/app.js', './js/state.js', './js/data.js', './js/themes.js',
  './js/views/equipos.js', './js/views/cromos.js', './js/views/repes.js', './js/views/stats.js',
  './data/initial-progress.json',
  './icons/icon-192.png', './icons/icon-512.png', './icons/icon-maskable-512.png',
  // + every font file added in Task 3, listed explicitly here
];

self.addEventListener('install', (event) => {
  event.waitUntil(caches.open(CACHE).then((cache) => cache.addAll(PRECACHE_URLS)).then(() => self.skipWaiting()));
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((keys) => Promise.all(keys.filter((k) => k !== CACHE).map((k) => caches.delete(k))))
      .then(() => self.clients.claim())
  );
});

self.addEventListener('fetch', (event) => {
  if (event.request.method !== 'GET') return;
  event.respondWith(
    caches.match(event.request).then((cached) => cached || fetch(event.request).then((response) => {
      const copy = response.clone();
      caches.open(CACHE).then((cache) => cache.put(event.request, copy));
      return response;
    }).catch(() => cached))
  );
});
```

Fill in the real font filenames from Task 3 in `PRECACHE_URLS` before committing.
